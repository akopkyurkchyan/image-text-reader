=== GOOGLE PLAY — DATA SAFETY FORM (guidance for Image to Text) ===

Does your app collect or share user data?
→ No (for server-side collection). Processing is on-device only.

Data types — typically declare as NOT collected for:
• Personal info (name, email, etc.)
• Financial info
• Location
• Contacts
• User IDs
• App activity (analytics) — unless you add analytics later

If Play asks about Photos and videos:
• Accessed: Yes (user selects/captures images)
• Collected: No (not sent to your servers)
• Shared: No
• Processed ephemerally on device: Yes
• Purpose: App functionality (OCR)
• Optional: User chooses when to use camera/gallery

If Play asks about Device or other IDs:
→ No, unless a dependency collects them (this app has no analytics SDK)

Encryption in transit:
→ N/A for user content (not transmitted). Standard HTTPS if any framework traffic.

Can users request data deletion?
→ N/A — no account, no server storage. User can uninstall the app.
